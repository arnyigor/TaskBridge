Как устроен TaskBridge

Проекты и сессии

Проект — это папка с кодом, зарегистрированная в настройках сервера (в файле config.json). Сессия (задача) — это один разговор с Pi внутри проекта: сообщение, ответы, инструменты, файлы. Если проект всего один, выбор проекта не показывается — он подставляется сам. «Без проекта» — временная рабочая папка, которая не привязана к твоему коду; используй её для разовых экспериментов.

Кнопка «+ проект» рядом с выбором проекта открывает выбор папки прямо с телефона — но только внутри заранее разрешённых корневых директорий (projectBrowser.roots в config.json), а не по всему диску. Выбранная папка сразу и навсегда сохраняется как новый проект. Кнопка «🗑 Проекты» удаляет проект из списка TaskBridge — сама папка и уже созданные в ней сессии не трогаются.

Как это работает

TaskBridge — это веб-интерфейс к Pi (коммандному ИИ-агенту), который крутится на компьютере. Телефон и компьютер видят один и тот же список сессий, потому что оба просто открывают один и тот же сервер в браузере — сессия не привязана к устройству, с которого её создали.

Отправка сообщений

Enter отправляет сообщение, Shift+Enter — перенос строки. Можно приложить файлы кнопкой-скрепкой (📎) — они потоково загружаются на сервер и попадут в рабочую папку проекта, а в подсказке для Pi будет список путей. Файл можно отправить и без текста — TaskBridge подставит заголовок «Прикреплённые файлы». Крестик в поле ввода очищает текст и вложения. Пока сообщение не отправлено, черновик (текст и файлы) сохраняется при переключении между сессиями и не потеряется, если случайно перейти в другую сессию.

Файлы: вложения и результаты

У каждого вложения — своя карточка с двумя ссылками: открыть (просмотр в браузере, для картинок и PDF) и «⭳» — скачать с исходным именем. Файлы, которые Pi создал или изменил во время работы, автоматически появляются в блоке «Файлы агента» в панели сессии — их не нужно искать вручную через инструменты.

Markdown и код

Ответы Pi рендерятся как настоящий Markdown: списки, таблицы, ссылки и картинки на файлы проекта кликабельны. У каждого блока кода есть кнопка «Копировать»; у каждого ответа целиком — кнопка 📋 рядом со статусом.

Модель (Pi models и профили запуска)

Кнопка «Модель: …» над полем ввода открывает список моделей напрямую из Pi — те же provider'ы, ключи и модели, что видны командой /model (включая удалённые провайдеры, не только локальный llama.cpp). Если сессия выбрана, смена применяется к ней сразу и сохраняется в её истории; если нет — выбор запомнится для следующей новой задачи. Рядом можно задать thinking level.

Если в настройках заданы профили запуска локальной модели, в шапке дополнительно появляется выбор профиля («Текст» / «Vision») и кнопка запуска: ▶ — запустить, ⟳ — перезапустить. Профиль Vision понимает картинки, профиль Текст — нет. Перезапуск безопасен: TaskBridge проверяет, что процесс на нужном порту — это действительно модель из твоих профилей, а не что-то постороннее.

Локальный health-check и выбор профиля применяются только к провайдеру, указанному в localRuntime.provider (по умолчанию llamacpp). Для моделей других провайдеров они пропускаются — важно, чтобы выбранная модель была доступна Pi.

Статус в правом верхнем углу — цветной кружок: зелёный — модель свободна, фиолетовый — занята, красный — не отвечает. Если включён AUTO-выбор профиля, TaskBridge сам подставит vision-профиль, когда во вложении есть картинка.

Применение изменений (worktree)

Когда задача выполняется в git worktree, основной проект не трогается. В панели сессии появятся кнопки «Применить к проекту» — применяет результат к исходному репозиторию (нужны чистый репозиторий и тот же HEAD, что при создании worktree; есть force), и «Удалить worktree» — убирает рабочую копию. Удаление сессии тоже чистит её worktree.

Импорт сессии Pi из терминала

Кнопка «Импорт сессии Pi» показывает сессии, найденные на диске (созданные командой pi в терминале, а не через TaskBridge): они сгруппированы по проектам, есть поиск и предпросмотр (модель, thinking, число сообщений, последние фразы). После нажатия «Продолжить в TaskBridge» выбранная сессия становится обычной сессией TaskBridge — дальше с ней можно работать с любого устройства.

По умолчанию TaskBridge делает безопасную копию: разговор переносится в собственную папку TaskBridge, а оригинальный файл в терминале не меняется и его можно открыть в Pi как раньше. Второй режим — «Забрать оригинал»: сессию дальше ведёт только TaskBridge. Его стоит включать, если вы уверены, что терминальный Pi закрыт: при одновременной записи с двух сторон файл может испортиться.

Если вы только что закрыли сессию в терминале (файл менялся меньше 10 минут назад), TaskBridge предложит её отдельной строкой над списком — чтобы не искать её вручную.

Подключение с телефона

Если в настройках включена авторизация — на компьютере нужно нажать «Подключить телефон», получить 8-значный код и ввести его на телефоне. Код действует 10 минут.

Для уведомлений о завершении задачи и системного буфера обмена браузеру нужен «безопасный контекст» — то есть HTTPS. TaskBridge поднимает свой HTTPS с самоподписанным сертификатом; при первом заходе браузер покажет предупреждение «небезопасно» — это нормально для самоподписанного сертификата в локальной сети, нужно один раз подтвердить «всё равно перейти».

Колокольчик в шапке — это переключатель: нажатие включает или выключает уведомления в TaskBridge (включённый колокольчик подсвечен жёлтым, курсор показывает подсказку). Само разрешение браузера так отозвать нельзя — если нужно запретить уведомления полностью, это делается в настройках сайта в браузере.

Поиск и переименование

Строка поиска над списком сессий фильтрует по названию/тексту задачи. Карандаш рядом с названием сессии — переименование, чтобы не искать нужный разговор по автоматическому ID.

Ввод: Enter — поставить сообщение в очередь (очередь видна над полем ввода, оттуда можно отправить раньше или убрать), Ctrl+Enter — отправить сразу, не дожидаясь модели, Shift+Enter — перенос строки. Несколько сообщений к одной сессии ждут своей очереди по порядку.

Список разбит на две группы: Активные (что Pi делает прямо сейчас: в очереди, готовит папку, работает, ждёт ответа) и Недавние (завершённые, свежие сверху). В строке видно статус, проект, модель и когда сессия обновлялась. 🔗 копирует ссылку на сессию — её можно открыть на телефоне или в другом браузере.

Адрес сессии

У каждой открытой сессии свой адрес: /session/<id>. Он меняется при выборе сессии, поэтому страницу можно обновить (F5), поставить в закладки или открыть по ссылке на другом устройстве — откроется тот же разговор. Закрытие браузера работу Pi не останавливает. Поиск задания, создание и импорт новой сессии возвращают адрес в /.

Известные ограничения этой версии

  • Нет обнаружения занятости терминальной сессии Pi — только предупреждение (в режиме «Забрать оригинал»).
  • История сессий не чистится автоматически — только удаление вручную.
  • Уведомления и буфер обмена через системный API работают только по HTTPS/localhost.
