Провайдеры

Первый шаг: безопасная настройка собственных OpenAI-совместимых API для Pi.

Подключения

Существующие провайдеры — только для просмотра. TaskBridge редактирует только записи, которые создал сам (ID tb-*).

Новое подключение

Pi

Вводи только имя переменной, не значение ключа. Локальным API без ключа оставь поле пустым. Секрет никогда не отправляется из этой формы.

Вводи реальные ID, которые принимает API. Большие каталоги лучше не импортировать целиком.

Как пользоваться

1. Добавь подключение и список моделей. 2. Если используется API-ключ, задай указанную переменную окружения в процессе запуска TaskBridge и перезапусти сервер. 3. Проверь GET /models, затем обнови каталог в TaskBridge и выбери модель. Текущие работающие сессии не перенастраиваются.

Проверка /models не запускает генерацию, не доказывает поддержку инструментов и не тратит токены генерации (провайдер может тарифицировать собственные запросы иначе). Генерацию проверяй отдельно из новой тестовой сессии.

Запись доступна только с компьютера через localhost. Ключи и сторонние конфиги здесь намеренно не редактируются. Полный мастер авторизации и OMP-адаптер — в следующих этапах.
