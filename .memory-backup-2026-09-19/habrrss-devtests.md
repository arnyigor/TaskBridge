# HabrRSS: пейджинг + комплексный прогон на устройстве (v1.0.9, коммит e841d01, тег v1.0.9 запушен)

## Подключение к телефону (OnePlus 6T, 192.168.1.132)
Wireless debugging: на телефоне «Отладка по Wi-Fi» → «Подключение с помощью кода» → на ПК:
`adb pair 192.168.1.132:<pairPort> <код>` → `adb connect 192.168.1.132:<debugPort>`.
Если connect даёт «cannot connect / device not found» — использовать TLS-транспорт из `adb devices`:
`adb -s 'adb-00bed473-KzCMq5 (2)._adb-tls-connect._tcp' <cmd>` (имя со пробелом/скобками — в кавычках).
Порт отладки меняется после каждого переподключения — брать с экрана телефона.

## ГРАБЛИ тестирования (важно)
1. **Клавиатура**: программные свайпы в нижней половине экрана при открытом IME приводят к gesture typing → в поле поиска появляется мусор («by by by»), и приложение переключает фид. ПЕРЕД прокруткой проверять: `dumpsys input_method | findstr mInputShown` → если true, `input keyevent 4`.
2. **Системные жесты**: свайпы от самой нижней/верхней кромки → Home/шторка. Безопасная зона: y от 1500 до 500.
3. **Шторка уведомлений залипает** (mCurrentFocus=NotificationShade): `cmd statusbar collapse`, `am broadcast CLOSE_SYSTEM_DIALOGS`, monkey — НЕ помогают. Помогает: `input swipe 540 2200 540 200 300` + `keyevent 4` ×2 (иногда уходит в keyguard; разблокировать сам не могу — нужен пользователь).
4. `uiautomator dump` → файл в UTF-16: `[xml]$x = Get-Content -Raw -Encoding Unicode <path>`.
5. `input text` — только латиница; пробел = `input keyevent 62`.
6. AppLog в release-сборке в logcat не пишется — проверять по UI-дампам/скриншотам.

## Замечания из прогона (не исправлены)
- Память поднимается до ~144 МБ при быстрой прокрутке обложек → настроить Coil (memoryCache 15–20%, requestSize баннера 720→512).
- «1 статей» — нет согласования числа в сводке.
- Фильтр поиска/тега переносится между разделами (в «Сохр.» список был отфильтрован тегом).
- Авто-резюм импорта после перезапуска приложения отсутствует (нужно нажать кнопку).
