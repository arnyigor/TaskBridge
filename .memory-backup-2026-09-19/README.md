## Почему этот бэкап вообще нужен

Исходные заметки живут в каталоге, который **игнорируется git**:
`.gitignore:43` → `/data/`. Проверено: `git ls-files data/persistent_memory/` = 0 файлов,
`git log -- data/persistent_memory/*` — пусто.

То есть **у заметок нет истории версий**, и восстановить случайно затёртую заметку было нельзя.

Дополнительно: `manage_project_memory` вызывает `_enforce_storage_limits()`
(`src/mcp_tools/core.py:173`) сразу после записи файла. При `MAX_ACTIVE_PROJECTS = 10`
и текущем количестве тем **ровно 10** — следующий `save` новой темы молча удалит
старейшую заметку.
