# experiments/cont-00 — преждевременные остановки Pi

Отвечает на вопрос «нужно ли автопродолжение» до его разработки: семь задач с
машинно проверяемым критерием готовности, два режима (один ход против «доп. ход
после неудачной проверки»), одинаковые модель и промпт.

Результаты и решение — [docs/cont-00-premature-stops.md](../../docs/cont-00-premature-stops.md).

```bash
# фикстуры + доказательство, что проверки отличают готовое от неготового
node experiments/cont-00/fixtures/build.mjs .local/cont00/fixtures --self-test

# прогон: 7 задач × 2 режима
node experiments/cont-00/run-cont00.mjs --mode both --timeout 300000
node experiments/cont-00/run-cont00.mjs --mode b --only T6-plan-eight-steps
```

- Готовность решает `check.mjs` в рабочей копии, а не текст ответа модели;
  `claimedDone` пишется отдельной колонкой — «сказала готово» ничего не доказывает.
- В режиме B следующий ход несёт только вывод проверки, без уговоров и
  «пожалуйста, продолжи»; число таких ходов ограничено `--max-extra` (3).
- Результаты — в `.local/cont00/run-*` (вне Git): `run.json` на прогон,
  `summary.json` на серию.
