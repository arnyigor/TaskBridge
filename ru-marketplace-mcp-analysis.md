# Анализ: Vladimir-Human/ru-marketplace-mcp

**Дата проверки:** 2026-09-21 · **Версия:** v2.4.2 · **Лицензия:** MIT
**Метод:** клонирование в `ru-marketplace-mcp/`, офлайн-тесты, живые запросы к Wildberries, stdio-проверка MCP-сервера, запуск `doctor`.

---

## 1. Что это

MCP-серверы для чтения данных с 14 российских/китайских маркетплейсов: Wildberries, Ozon, Яндекс Маркет, Детский мир, Авито, AliExpress, Taobao, Мегамаркет, Lamoda, DNS, Ситилинк, Циан + сравнение цен + опциональный MPStats. **Только чтение.** Ключи API и регистрация не нужны — площадки с анти-ботом читаются через собственный Chrome пользователя (CDP).

## 2. Что нужно для работы (проверено)

| Требование | Статус |
|---|---|
| Python 3.12+ | ✅ 3.12.10 на стенде |
| uv | ✅ 0.12.13 — `uv sync --all-packages` прошёл без ошибок |
| Node.js | только для тестов разработчика, для работы сервера не нужен |
| Chrome + CDP (порт 9222) | нужен 9 источникам из 14; WB, Яндекс Маркет, Детский мир, карточки Lamoda — анонимно |
| Российский домашний IP | обязателен для Авито (датацентр = блок), сильно помогает Ozon |
| Активный вход в площадку | Taobao, Мегамаркет — без него пусто/login wall |
| `MPSTATS_MP_AUTH` | опционально; без токена сервер стартует, mpstats-инструменты отвечают `auth_missing`, остальные 13 серверов не затронуты |

## 4. Качество проекта — высокое

- **Монорепо на uv workspace:** 16 пакетов (mcp-core + 14 коннекторов + объединённый marketplace-connector), 255 Python-файлов, ~50 700 строк Python.
- **1756+ офлайн-тестов** + property-based (hypothesis) + ops-gate скрипты (покрытие, запрет print, количество тестов, версии).
- **Честная самодиагностика:** в README прямо написано «Проверка 2.4.2: доступность всех площадок не подтверждена» — редкость для таких проектов. `doctor` различает `success / drift_detected / inconclusive` и объясняет причину каждой блокировки.
- **Безопасность продумана:** CDP-предупреждения, отдельный scraping-профиль Chrome, allowlists на хосты, схема-гвард `open_page`, никакие креды не хранятся.
- **Забота о токенах:** измеритель стоимости MCP-схем по проводам (`mcp_wire.py`), переменная `MARKETPLACE_SOURCES` для среза источников.
- Активная разработка: последний коммит — день проверки (2026-09-21).

## 5. Насколько полезен

**Кому:** продавцам/арбитражникам (цены конкурентов, остатки, динамика), покупателям (сравнение «где дешевле» одним вызовом), проверке контрагентов (`wb_seller` отдаёт юрлицо, ИНН/КПП/ОГРН), аналитике недвижимости (Циан).

**Сильные стороны:**
- Единый интерфейс к 14 площадкам, работающий через анти-бот без платных API и регистраций.
- Полезные редкие инструменты: реквизиты продавца WB, вопросы-ответы покупателей, сравнение цен по всем источникам одним вызовом.
- Тестируемость и самодиагностика на уровне коммерческого проекта.

**Ограничения и риски:**
1. **Хрупкость по природе:** чтение чужих внутренних API/HTML — площадки меняют их без предупреждения. Инструменты самопроверки (`doctor`, selfcheck, baseline-drift) это компенсируют, но ломаться будет.
2. **Цена в контексте:** полный монтированный сервер стоит **~13,6 тыс. токенов в каждом запросе**. Рекомендуемый режим — срез `MARKETPLACE_SOURCES` (~0,9 тыс.) или набор skills из `dsh/`.
3. **Условия эксплуатации:** Авито и ряд других площадок без русского домашнего IP + залогиненного Chrome работать не будут — с датацентрового/западного IP покрытие падает с 14 до ~4 источников.
4. Правовая серая зона скрейпинга (ToS площадок), хоть код и read-only и не хранит креды.

**Вердикт: 8/10** в своей нише. Это явно не «toy project»: тесты, докер, безопасность, самодиагностика, документация. Для задач с WB/Яндекс Маркетом/Детским миром (анонимные источники) — работает сразу и стабильно. Полный потенциал раскрывается только при российских домашнем IP + настроенном CDP-профиле Chrome.
