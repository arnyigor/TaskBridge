## Инварианты

1. commandId создаёт не более одного логического действия.
2. События изолированы по сессии.
3. Финальный Run не становится RUNNING самопроизвольно.
4. Подтверждённые сообщения устойчивы к restart.
5. Завершать процесс можно только при доказанном владении.
6. Reconnect сам по себе не меняет состояние команды.
7. Resume Context не изменяет Run.
8. Cloud не обходит авторизацию и approvals.
