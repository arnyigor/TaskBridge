# Зафиксированный вариант чата

Решение пользователя от 2026-10-29: сохранить компактную компоновку чата в Web, Desktop и Android. Не менять её без нового прямого запроса пользователя.

## Обязательная компоновка

- Размышления объединены в один сворачиваемый блок сверху.
- Инструменты показаны компактными группами по типу над ответом.
- Промежуточный текст и ответ объединены в один непрерывный Markdown-блок снизу.
- Копирование ответа использует канонический текст без команд и размышлений.
- Текст не разбивается на визуальные сегменты между вызовами инструментов.

## Данные и диагностика

Порядок серверных событий, состояния отдельных вызовов и границы Compact сохраняются в данных. Их нельзя удалять ради компактного отображения. Канонический ID ответа остаётся общим для редактирования, продолжения, регенерации и ветвления.

Хронологическая проекция сохранена для диагностики и тестов, но не является основным отображением. Отдельное действие подробного просмотра пока не реализовано; добавлять его без запроса не требуется.

Прежнее предложение сделать хронологическую ленту основным чатом в `CHAT_RUN_ORDER_FIXES.md` отменено этим решением. Возвращать его автоматически или продолжать прежний UI-план нельзя.

## Проверки и приёмка

- Адресные последовательные проверки: 214 Web/backend-тестов прошли, 1 пропущен; 36 KMP-тестов прошли; 6 интеграционных сценариев Compact, SSE/reconnect, STOP и двух клиентов прошли.
- JAR установленного Desktop совпали по SHA-256 с собранными артефактами.
- Ручная проверка интерфейса и проверка на телефоне не подтверждены; подключённого ADB-устройства нет. Полный набор тестов не имеет подтверждённого успешного завершения.
- По решению пользователя окончательная приёмка проводится в рабочем режиме. Обнаруженные проблемы оформляются отдельными багами; это не основание самовольно менять зафиксированную компоновку.
