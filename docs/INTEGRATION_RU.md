# TaskBridge — Provider Setup v1 (MR-C01 pilot)

**База:** `codex/stabilize-taskbridge-20261015`, commit `bf3f26c1a73edd4a1ea7ac34c453c6a3d19f4992` (TaskBridge 1.2.3).

## Что добавлено

- `src/providers/pi-provider-profiles.mjs`: отдельный адаптер для управления **только собственными** Pi-провайдерами `tb-*` через `~/.pi/agent/models.json`.
- `web/providers.html`, `providers.js`, `providers.css`: простой web-интерфейс по `http://127.0.0.1:8787/providers.html`.
- API `GET/PUT /api/provider-profiles`, `DELETE /api/provider-profiles/:id`, `POST /api/provider-profiles/:id/check` (доступ только через localhost на компьютере).
- `tests/pi-provider-profiles.test.mjs`: проверка записи и восстановления, безопасности URL/секретов и диагностики без генерации токенов.

## Что не изменено

- Старые провайдеры в `models.json`, их настройки/ключи/модели (показываются read-only).
- Серверная LAN-авторизация, все сессии, SQLite, Pi RPC, Android KMP.
- Codex CLI, облачный Relay и OMP **не подключались**. Их нет в этом MR.

## Интеграция

1. Сохраните собственные изменения, выполните резервное копирование `data/`, `config.json`, `~/.pi/agent/models.json`, особенно если Pi запущен.
2. Работайте на `codex/stabilize-taskbridge-20261015` или совместимом её потомке. **Не накладывайте этот patch на старый master 0.11.0.**
3. Распакуйте архив в любую папку, например `C:\Temp\tb-provider-v1`.
4. Откройте PowerShell в каталоге вашего репозитория TaskBridge:

   ```powershell
   git status --short
   git apply --check C:\Temp\tb-provider-v1\changes.patch
   git apply C:\Temp\tb-provider-v1\changes.patch
   node --test tests/pi-provider-profiles.test.mjs
   npm run check
   npm test
   ```

5. Перезапустите TaskBridge обычным способом. На компьютере откройте `http://127.0.0.1:8787/providers.html`, либо ссылку «Провайдеры» в веб-интерфейсе.
6. Добавьте свой OpenAI-compatible endpoint (`tb-...`), настоящий ID модели и **имя** переменной окружения API-ключа. Для local endpoint ключ не требуется.
7. Укажите значение переменной окружения *в окружении процесса, запускающего TaskBridge*. Например, в текущем PowerShell для теста:

   ```powershell
   $env:MY_PROVIDER_API_KEY = '...'  # секрет вводится локально, не в web UI
   npm start
   ```

   **Осторожно:** не делайте коммит этого значения, не вставляйте его в публичные логи и не отправляйте в чат. В portable/служебном запуске окружение может задаваться иначе.
8. Нажмите «Проверить /models». Если сервер отвечает, обновите каталог моделей в TaskBridge (`/api/models?refresh=1`) и отправьте короткий запрос **из новой сессии** для проверки инструментов/генерации.

## Безопасность и ограничения

- Для правки требуется `access.local(req)` (именно loopback, не телефон по Wi-Fi). Страница с телефона откроется, но запросы управления будут отклонены.
- API-ключи не принимаются и не возвращаются. Только ссылки на переменные окружения вида `$MY_PROVIDER_API_KEY`. Значения ключей **не сохраняются** в `models.json` этим кодом.
- Поддерживается `api: openai-completions`, не все модели совместимы с таким протоколом. Для нативных OpenAI Responses, сложных параметров, OAuth и специфичных провайдеров потребуется следующий MR.
- Не импортируются автоматически сотни моделей: до 100 явно указанных ID на профиль. Метаданные для неизвестных моделей не выдумываются. У уже заведённых моделей сохраняются существующие `compat` и другие поля.
- Проверка `GET /models` не означает, что модель сможет выполнить tool calling. Она не делает пробную генерацию и по умолчанию не должна расходовать токены, но провайдер может установить собственную тарификацию.
- На каждую запись сохраняется резервная копия `models.json.bak-taskbridge-*`. Перед записью проверяется SHA-256 файла. Внешние редакторы, одновременно меняющие `models.json` точно в интервале между проверкой и atomic rename, теоретически могут создать гонку: **не редактируйте файл одновременно вручную**.
- Признак владения — поддерживаемое Pi поле `name: "TaskBridge: tb-..."` вместе с префиксом ID `tb-`. Нестандартные поля в Pi JSON не добавляются. Это пилот совместимости, а не универсальная миграция конфигурации.
- Новые настройки доступны после обновления каталога / перезапуска Pi-сессии, текущие работающие сессии не перенастраиваются.

## Как откатить

До коммита:

```powershell
git apply --reverse C:\Temp\tb-provider-v1\changes.patch
```

Это откатывает только исходный код. Изменения `~/.pi/agent/models.json`, сделанные через UI, откатываются отдельно — восстановлением соответствующего `models.json.bak-taskbridge-*` **после остановки Pi/TaskBridge**.

После успешной интеграции зафиксируйте изменённые файлы отдельным коммитом, без `git add -A`.

## Что остаётся на следующие MR

- MR-A00/А01: стабилизация baseline и подтверждение аварийных сценариев на вашей Windows-машине.
- MR-C02: единый KMP-экран для Android и Desktop, шаблоны всех известных провайдеров, выбор моделей из каталогов.
- MR-C03: безопасная установка API-ключа через локальное credential store, без передачи секретов по LAN; настоящий test-generation только по кнопке.
- MR-C04+: фильтры, избранное, профили, лимиты, статистика.
- MR-E: OMP только после приёмки остального функционала.

## Реальная проверка пакета

В изолированном Node.js 22 выполнены тесты модуля и синтаксические проверки. **Полный `npm test`, компиляция KMP, живой Pi на Windows и UI-интеграция на вашем реальном репозитории здесь недоступны.** Эти результаты должен подтвердить пользователь.
